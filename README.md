# Addicted Gym — юридические страницы

Статический сайт с политикой конфиденциальности, условиями использования и
страницей удаления аккаунта. Все страницы на трёх языках: русский, английский,
казахский.

Опубликован через GitHub Pages: https://morphinemeplz.github.io/addicted-gym-legal/

| Страница | Где используется |
|---|---|
| `privacy.html` | App Store Connect, Play Console, ссылка в приложении |
| `terms.html` | App Store Connect, ссылка в приложении |
| `delete-account.html` | Play Console → Data Safety: удаление аккаунта без установки приложения |

Исходники лежат также в репозитории приложения, в папке `legal/` — правки удобнее
делать там и копировать сюда.
